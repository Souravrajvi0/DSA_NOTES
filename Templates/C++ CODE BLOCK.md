# C++ Code Block Template

## Basic Code Block with Complexity

```cpp
// Your code here

```

**⏱️ Complexity:**
| Complexity Type  | Value   |
| ---------------- | ------- |
| Time Complexity  | **O()** |
| Space Complexity | **O()** |

---

## Quick Snippets

### Function Template
```cpp
returnType functionName(parameters) {
    // code
    return result;
}
```

### Class with Constructor
```cpp
class ClassName {
private:
    // private members

public:
    // Constructor
    ClassName(parameters) {
        // initialization
    }

    // Member function
    returnType functionName(parameters) {
        // code
    }
};
```

### Lambda Function
```cpp
auto lambda = [](parameters) {
    // code
    return result;
};
```

### If-Else
```cpp
if(condition) {
    // code
} else if(condition2) {
    // code
} else {
    // code
}
```

### For Loop
```cpp
for(int i = 0; i < n; i++) {
    // code
}
```

### While Loop
```cpp
while(condition) {
    // code
}
```

### Switch Case
```cpp
switch(variable) {
    case value1:
        // code
        break;
    case value2:
        // code
        break;
    default:
        // code
}
```
